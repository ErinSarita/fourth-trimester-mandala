# The Fourth Trimester Mandala

A teaching map of the first twelve weeks after birth, read from the center out: the dyad (mother and baby) at the center, then the baby, the mother, the partner, the wider circle of support, the educator (the PPN view and the science behind each moment), and best practices for each moment.

This is the shorter version, kept to the material from the course and its suggested reading. The workbook, booklet, and visitor cards, and the Her language and Support guides, are left out for now. The full version is kept on the `full-version` branch of this repository, and the full version with the narrowed reference list is on `full-version-trimmed-references`.

The wheel begins at the top with the foundations (warmth, milk, and love: Bergman's habitat and niche), then moves clockwise through the first hour (Widström's nine stages), the first days (day 1 to two weeks), and the first months (weeks 3 to 12).

Created by Erin Singleton, a student in APPPAH's Prenatal & Perinatal Educator certification. It continues from The Pregnancy and Birth Mandala. An educational map, not medical advice.

The mandala is the single file `index.html`, with the Key concepts in `key-concepts.js`. Its content lives in the `SLICES` array (twelve slices, each with the baby, mother, partner, circle, educator, best practices, and a repair), plus `QUARTERS`, `NEEDS`, `STAGES`, and the Co-regulation page's content: `HORMONES`, `COREG`, and `WAYS`. Under each reference, a "Cited in" note links to the places that cite it, and under each section, a "Sources" note links to the references it uses. Settings saved in the browser use the `ft-` prefix (`ft-theme`, `ft-born`).
